# Naroju Chaitanya — Portfolio

A responsive, single-page developer portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish using GitHub Pages
1. Create or open the GitHub repository where you want this portfolio.
2. Upload `index.html`, `styles.css` and `script.js` to the repository root.
3. In repository Settings → Pages, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish your site.

## Before publishing
- Your LinkedIn profile link is prefilled; verify it before publishing.
- Add your preferred profile photo if you want one; the current design uses a CSS code illustration.
- Verify each project description and link, and add direct repository links where available.
- Add a resume PDF link if you want recruiters to download your resume.

The site uses Google Fonts, so the font styling falls back to system fonts if Google Fonts are unavailable.
